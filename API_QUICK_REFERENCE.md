# 🚀 Quick Reference - Backend API

**Cycling Routes MVP Backend - API Quick Reference**

---

## 🔐 Authentication

### Sign Up
```bash
POST /auth/signup
Content-Type: application/json

{
  "email": "user@example.com",
  "username": "username",
  "password": "securepassword",
  "displayName": "User Name" # optional
}

# Response
{
  "accessToken": "eyJhbGc...",
  "refreshToken": "eyJhbGc...",
  "user": {
    "id": "user-id",
    "email": "user@example.com",
    "username": "username",
    "displayName": "User Name"
  }
}
```

### Sign In
```bash
POST /auth/signin
Content-Type: application/json

{
  "email": "user@example.com",
  "password": "securepassword"
}

# Same response as signup
```

### Refresh Token
```bash
POST /auth/refresh
Content-Type: application/json

{
  "refreshToken": "eyJhbGc..."
}

# Response
{
  "accessToken": "eyJhbGc..."
}
```

### Using Token
```bash
# All protected endpoints require:
Authorization: Bearer {accessToken}
```

## 🚴 Rides

### Create Ride
```bash
POST /rides
Authorization: Bearer {token}
Content-Type: application/json

{
  "id": "ride-001",                    # generated by frontend
  "mode": "GPS_ONLY",                  # or GPS_CAMERA
  "startedAt": "2026-05-24T10:00:00Z",
  "title": "Morning ride",             # optional
  "description": "Scenic route",       # optional
  "tags": ["morning", "scenic"]        # optional
}

# Response
{
  "id": "ride-001",
  "userId": "user-id",
  "mode": "GPS_ONLY",
  "status": "ACTIVE",
  "distance": 0,
  "duration": 0,
  "averageSpeed": 0,
  "maxSpeed": 0,
  "startedAt": "2026-05-24T10:00:00Z",
  "finishedAt": null,
  "createdAt": "2026-05-24T..."
}
```

### List Rides
```bash
GET /rides?page=1&limit=20&status=FINISHED
Authorization: Bearer {token}

# Response
{
  "data": [...],
  "total": 42,
  "page": 1,
  "limit": 20,
  "hasMore": true
}
```

### Get Ride
```bash
GET /rides/:id
Authorization: Bearer {token}
```

### Get Ride with Full Route
```bash
GET /rides/:id/with-route
Authorization: Bearer {token}

# Response includes route points and snapshots
{
  "id": "ride-001",
  ...ride data...,
  "route": [
    { "latitude": 40.7128, "longitude": -74.0060, ... },
    ...
  ],
  "snapshots": [
    { "id": "snap-1", "imageUrl": "...", ... },
    ...
  ]
}
```

### Update Ride
```bash
PATCH /rides/:id
Authorization: Bearer {token}

{

  "distance": 42.5,
```

### Finish Ride
```bash

Authorization: Bearer {token}

{
  "finishedAt": "2026-05-24T11:00:00Z",
```

### Delete Ride
```bash
DELETE /rides/:id
Authorization: Bearer {token}

# Response

```

## 📍 Route Points (GPS)

### Add Single Point
```bash
POST /rides/:id/points
Authorization: Bearer {token}
Content-Type: application/json

{
  "latitude": 40.7128,
  "longitude": -74.0060,
  "altitude": 10.5,           # optional
  "speed": 12.5,              # optional
  "heading": 180.0,           # optional
  "accuracy": 5.0,            # optional
  "timestamp": "2026-05-24T10:01:00Z"
}
```

### Bulk Add Points (PREFERRED)
```bash
POST /rides/:id/points/bulk
Authorization: Bearer {token}
Content-Type: application/json

{
  "points": [
    {
      "latitude": 40.7128,
      "longitude": -74.0060,
      "altitude": 10.5,
      "speed": 12.5,
      "heading": 180.0,
      "accuracy": 5.0,
      "timestamp": "2026-05-24T10:01:00Z"

    ... more points ...
  ]
}

# Response
{ "created": 100 }
```

### Get Points

## ⚙️ Common Status Codes

| Code | Meaning |
|------|---------|
| 200 | OK - Request successful |
| 201 | Created - Resource created |
| 400 | Bad Request - Invalid input |
| 401 | Unauthorized - Missing/invalid token |
| 403 | Forbidden - Access denied |
| 404 | Not Found - Resource doesn't exist |
| 409 | Conflict - Resource already exists |
| 500 | Server Error - Backend error |

---

## 💡 Tips

1. **Always include** `Authorization: Bearer {token}` for protected endpoints
2. **Bulk operations** are preferred (e.g., `/points/bulk` instead of `/points`)
3. **Pagination** defaults: rides=20, points=500, snapshots=100
4. **Timestamps** are ISO 8601 format
5. **Token expires** in 7 days (refresh needed)
6. **IDs** are UUIDs or cUIDs
